# 🌐 Extruying 3D

Sitio web oficial de **Extruying 3D**  
Diseño industrial y futurista con detalles en **naranja neón**.  
Incluye animación del logo (3 pulsos), catálogo de productos e información de marca.

---

## 🚀 Cómo abrir la página

1. Descarga este proyecto completo.
2. Descomprime la carpeta `Extruying3D`.
3. Abre el archivo `index.html` con tu navegador (doble clic).
4. ¡Listo! Verás tu sitio funcionando localmente.

---

## ☁️ Cómo subirlo a GitHub Pages (hacerlo público)

1. Crea una cuenta en [https://github.com](https://github.com)
2. Inicia sesión y crea un nuevo repositorio llamado `extruying3d`
   - Marca **“Public”**
   - No marques “Add README”, ni `.gitignore`
3. En tu computador:
   ```bash
   git init
   git remote add origin https://github.com/TUUSUARIO/extruying3d.git
   git branch -M main
   git add .
   git commit -m "Versión inicial de Extruying 3D"
   git push -u origin main
